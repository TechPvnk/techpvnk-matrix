# TechPvnk Matrix

A cinematic cyberpunk CRT Matrix-style screensaver built with Electron, vibecoded by Alfredo Capella (TechPvnk).

TechPvnk Matrix recreates the iconic digital rain aesthetic with:
- red phosphor CRT rendering
- multi-monitor support
- BIOS-style boot sequences
- dynamic ASCII logo emergence
- retro terminal-inspired visuals
- ThinkPad-focused cyberpunk atmosphere

---

# Features

- Multi-monitor fullscreen rendering
- Dense Matrix-style code rain system
- CRT scanline + phosphor effects
- Dynamic TechPvnk logo materialization
- BIOS startup animation
- Low-end ThinkPad optimized mode
- GPU-friendly canvas renderer
